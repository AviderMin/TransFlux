# 02 · 产品需求与验收

## 用户流程

首次启动直接进入工作台，后台检查核心可用性并显示结果，不弹出教学向导。导入文件即异步探测；用户选择用途、质量和输出位置后点击“开始转换”。预检先报告问题，所有已就绪任务进入队列。完成后可打开文件夹、复制输出路径或从历史重新创建任务。

“加入队列”冻结当前配置；“开始转换”执行同样冻结再启动队列。后续修改工作台不影响已排队任务。对批量选择的设置修改只应用于选择项，混合值显示“多种值”。

## P0 功能矩阵

| ID | 必须实现 | 验收条件 |
|---|---|---|
| FR-01 | 文件选择器、多文件拖放、文件夹导入 | 默认不递归；递归需勾选；1000 文件可取消枚举，逐批出现 |
| FR-02 | 本地媒体探测 | 展示时长、分辨率、编码、音轨、字幕、HDR 状态；损坏文件单项报错 |
| FR-03 | 用途与预设 | 四个用途，质量/速度设置可理解；不支持的组合不能开始 |
| FR-04 | 批量与单项设置 | 支持全选/多选、单项覆盖、重置；面板明确影响对象数量 |
| FR-05 | 转码 | MP4/MKV H.264/AAC，保留/缩放、保留帧率、可选单段裁剪 |
| FR-06 | 音频导出 | M4A AAC、FLAC、WAV；无音轨时明确阻断 |
| FR-07 | 转封装 | 仅兼容组合流复制；不兼容时要求用户改模式，不悄悄转码 |
| FR-08 | 队列管理 | 排序、删除未启动任务、暂停队列、恢复队列、取消当前任务、失败重试 |
| FR-09 | 硬件自动与手动 | 自动、CPU、指定适配器/编码器；展示可用性与失败原因 |
| FR-10 | 输出保护 | 不覆盖源文件、冲突自动编号、输出验证后发布；取消残片不冒充成功 |
| FR-11 | 状态与恢复 | 进度、速度、估计剩余时间；崩溃后正在执行的任务标“已中断”，可重新开始 |
| FR-12 | 日志与历史 | 单任务诊断、导出脱敏报告、打开结果；可清空记录 |
| FR-13 | 设置 | 主题、语言、输出规则、并发上限、自动降级开关、日志清理 |
| FR-14 | 可访问性 | 全流程键盘可用、屏幕阅读器可读、200% DPI 与高对比验证 |
| FR-15 | 可重现计划 | 展示实际编码器、设备、流映射和只读命令参数；重试记录新的 attempt |

文件夹扫描不默认跟随重解析点/目录联接，不导入输出目录和已知临时文件，按规范化路径去重；不同硬链接是否重复不作保证。大批量扫描显示已发现数，不要求先算总数。探测失败不阻塞其他文件。

## 预设行为

| 用途 | 默认行为 | 用户必须知道 |
|---|---|---|
| 通用视频 | MP4 H.264 8-bit yuv420p + AAC，原分辨率原帧率 | 可选 1080p 上限，不默认放大 |
| 节省空间 | 同上，优先均衡压缩，允许选 1080p 上限 | 大小只估算，不保证比源小 |
| 提取音频 | 默认 M4A AAC 192 kbit/s，保留声道布局，能力不符则提示 | 无声道不添加静音；FLAC 不提高源音质 |
| 只换封装 | 选择 MP4 或 MKV，选中流全部 copy | 字幕/编码不兼容时必须处理后才能开始 |

默认视频仅选一条非封面视频和一条默认音轨；字幕默认不输出，源含额外轨道时在摘要持续显示“输出 1/3 音轨，字幕未包含”。用户开始后不再每项重复弹窗；在导入和选择变化时就明确呈现信息。高级面板允许选多音轨；MP4 软字幕首发只支持可验证的文本转换，位图字幕不支持；MKV 支持已验证可复制轨道。烧录字幕列 P1。

裁剪输入为相对源时间 `hh:mm:ss.mmm`，要求 `0 ≤ start < end ≤ duration`；已知时长之外阻断。转码裁剪按输出时间精确策略实现，转封装首发禁用裁剪，避免把关键帧截断误称为精确裁剪。

## 异常与边界

| 情况 | 必须行为 |
|---|---|
| 用户取消文件选择 | 保持原状，不显示错误 |
| 核心缺失或校验失败 | 工作台可用，开始按钮禁用；显示修复/重新安装入口 |
| 磁盘空间不足或未知 | 明确阻断或显示无法估计并要求用户确认；空间不足不自动换盘 |
| 输出同名 | 默认分配编号；保留独占目标预留；不提供默认覆盖 |
| 输入被移动或改写 | 启动前校验；发生变化转回待预检，不拿旧探测盲跑 |
| 硬件会话耗尽/驱动失败 | 按策略换候选路径、从头重试一次；任务卡可见原因与进度重置 |
| 用户指定 CPU/设备 | 手动模式默认禁止跨设备自动降级，提供显式重试选择 |
| 时长未知 | 显示不确定进度与已处理时长，不伪造百分比或 ETA |
| HDR/多视频/损坏流 | 按首发限制说明；不能静默降色深、丢主要流或猜测修复 |
| 退出且任务运行 | 弹出“留在应用 / 取消任务并退出”；不隐式后台常驻 |
| 系统休眠后恢复 | 检查进程与输入输出；失败归类为已中断，可重新开始 |

允许本地固定磁盘和 UNC 路径，UNC 断开按 I/O 失败处理；不保证跨网络原子提交，提交策略见 08。禁止 HTTP/RTSP 等 URL 输入。输出文件大于文件系统限制时预检说明；空间估计不构成充足保证。

## P1 与后续

P1：HEVC/AV1、HDR 保留与色调映射、字幕烧录、目标体积/两遍编码、逐流复制混合策略、更多设备预设、ARM64、便携分发、实测后提高并发。P2：视频合并、响度规范化、波形、插件扩展。每项都必须独立定义输入/输出语义与样片验收，不能仅添加按钮。

## 产品验收样例

AC-01：新装后导入 SDR MP4，保持默认用途和位置，只需点击一次开始，生成可播放文件且源哈希不变。

AC-02：批量加入含损坏、无音轨、HDR 的混合输入，单项给出问题，其他就绪项可开始；不会自动忽略用户需要处理的失败项。

AC-03：同源同配置同时排队两次，输出不同文件名；取消其中一项不影响另一项，磁盘和队列中均无假成功。

AC-04：硬件错误触发自动降级时，界面说明原路径、原因、新路径；输出只能来自完整新 attempt。

AC-05：关闭后重启不会继续向旧残片追加；历史保留失败原因，用户可显式从头重试。

## UX 修订（2026-11-01，与 03 同步）

- **转换工作台改为格式工厂式**：左侧按 视频/音频/图片 分类的目标格式目录，右侧任务与进度列表；
  开始/暂停作用于队列。移除左侧主导航与独立“任务/预设/设置”页面。
- **FR-03/FR-04 调整**：用途与参数不再在固定右侧面板展开，而是**每个任务项单独打开“目标格式参数”窗口**；
  多选相同目标时使用**批处理设置**窗口统一修改。参数窗口“预设优先，但允许输入具体数值”
  （CRF、目标码率、分辨率、帧率、采样率、声道、音频码率、裁剪等）。
- **预设（FR-03 相关）**：不再作为独立页面，内嵌于目标格式参数窗口（应用/另存为）。
- **FR-13 设置与诊断、关于**：统一放入**顶栏右侧**图标入口，以模态窗口呈现；诊断并入设置窗口的分区。
- **图片分类**：格式目录展示 图片（PNG/JPEG），首发禁用并说明 P1，不产生假按钮。
- 其余失败语义、输出保护、状态机与验收不变（见 07/08/09）。
