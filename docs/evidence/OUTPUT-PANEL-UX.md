# 输出设置面板交互优化

日期：2026-11-01。延续文件优先工作台及任务区/设置区 3:2 比例，优化右侧操作密度和分组。

## 已实施

- 输出格式：媒体形式/容器并排，视频/音频编码并排，保留父子归一化和多选混合值。
- 常用设置：匹配预设、质量/分辨率，支持自定义尺寸；无匹配预设时隐藏空预设入口。CRF/码率覆盖时质量显示“自定义参数”，不冒充标准质量档。
- 详细参数：视频、音频、裁剪/文件/元数据、保存预设四个独立原生 Expander，默认折叠，避免一次展开全部。转封装和音频模式继续按实际支持隐藏无关参数。
- 标题显示所选数量、即时生效/锁定状态；重置移到标题右侧，沿用原有确认逻辑。输出路径和两个目录操作固定在底部，参数正文单独滚动。
- UseBreakpoint(1100) 控制相关字段的双列/单列，使用类型化 Grid、WinUI 字阶、Space 间距和主题资源；所有字段保留自动化名称和禁用状态。比例/分组/断点为本项目选择，依据 [Reactor preview.16 官方布局文档](https://microsoft.github.io/microsoft-ui-reactor/0.1.0-preview.16/layout/)，不宣称是微软强制尺寸。
