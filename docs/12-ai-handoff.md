## 关键坑位提醒

- Render 内禁止 I/O 和进程启动；订阅卸载必须释放；稳定 key 和虚拟化关系到大队列性能。
- `UsePersisted` 不替代跨进程数据库；任务生命周期不能绑定页面生命周期。
- CPU libx264 与 LGPL-only 默认分发冲突；不要删掉许可事实使文档看似一致。
- ArgumentList 解决 shell 参数问题，不解决 FFmpeg filter 语法转义或媒体安全问题。
- 编码器存在不代表设备可用；设备索引不能在 DXGI/CUDA/QSV/AMF 间直接复用。
- 临时后缀不代表 muxer；必须显式 `-f`；`-n` 与预创建同名输出文件冲突。
- 取消与提交必须有边界；FFmpeg end/exit 0 都不独立代表成功。
- 文件 rename 与 SQLite 不能天然一起事务，恢复依赖 journal 与身份校验。
- 无时长就显示不确定进度；队列暂停不等于进程暂停；崩溃恢复不等于编码续传。
- source fingerprint 非加密全文件证明，执行前后检查且始终只读源文件。
- 不同编码器 CRF/CQ/QP 不可直接等价；性能比较须带质量和体积条件。
