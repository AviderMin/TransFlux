# 03 · UI / UX 设计规范

修订：2026-11-01（Asia/Shanghai）。本版替代此前的“左侧格式目录 + 固定列表 + 参数/批处理窗口”规范。

## 产品交互原则

先放入文件，再决定输出，检查后开始；转换中始终看得见、管得住，完成后能立即找到结果。
用户看到同一张任务卡片经历完整生命周期，不需要理解草稿、请求快照和执行队列。
采用原生 WinUI 3 + Microsoft.UI.Reactor，所有文件选择、主题、对话框保持 Windows 行为。

## 信息架构

- 顶部：应用名、历史记录、设置、关于。
- 主体左侧：文件任务卡片、添加文件/文件夹、全选/清除选择、移除已选、筛选。
- 主体右侧：所选任务的输出设置；没有选择时显示说明，不切换成隐藏的默认设置编辑器。
- 底部：完成/需处理/运行/等待数量、暂停后续任务/继续队列、开始转换 N 项。
- 图片转换、尚未实现的语言切换与日志清理不占据首版流程。

```text
┌ TransFlux                         历史  设置  关于 ┐
│ 添加文件  添加文件夹  全选  清除选择              │
│ ┌ 任务卡片 ──────────────────┐ ┌ 输出设置 ─────┐ │
│ │ ☑ A.mp4         待开始      │ │ 正在编辑 2 项 │ │
│ │   1080p · 02:35 · 320 MB    │ │ 输出格式 MP4  │ │
│ │   → MP4 · 均衡 · 保持原始   │ │ 预设/质量     │ │
│ │ ☑ B.mov         转换中 45%  │ │ 分辨率        │ │
│ │   [取消任务] [修改后转换]   │ │ 保存到        │ │
│ └────────────────────────────┘ │ 高级设置 ▸    │ │
│                                └───────────────┘ │
│ 1 项完成 · 1 项运行    暂停后续任务  开始转换 N 项│
└──────────────────────────────────────────────────┘
```

默认 1280×820 DIP，最小 920×640；主内容使用 Reactor Grid 的 `3* : 2*`，任务区约 60%、输出设置约 40%，扣除页边距和列间距后按比例分配。禁止将设置区固定为 320 DIP、把所有新增宽度只分配给任务区。卡片内容换行，动作按空间换行，避免固定表格列挤压文件名。
间距 4/8/12/16/24/32，遵循系统主题资源；颜色之外提供状态文字。

## 选择和参数修改

1. 导入文件不要求先选格式。新批次自动选中；单击文件名选中一项，复选框增减选择。
2. 右侧所有参数遵守同一范围：只修改已选、尚未入队的项目，即时生效，不设额外“应用”按钮。
3. 多选的不同字段显示“多种值”；只更新实际操作的字段，不将首项其他参数复制到全部项目。
4. 同时选择可编辑和已开始任务时，设置只读，避免悄悄只修改其中一部分。
5. 新增文件继承最近编辑的输出参数，但不继承文件名、裁剪范围与源轨道编号。
   目标格式/质量通过应用设置记忆；未启动项目的完整参数通过工作台持久化恢复。
6. 入队后参数冻结，显示与实际执行保持一致。队列等待项可以“移出队列并编辑”；执行中可“修改后转换”，建立独立的新卡片。
7. “开始转换 N 项”处理选择中的可开始项目；没有选择则处理全部可开始项目。阻断项目保留在原处并显示原因。

## 输出设置

基本设置按 **媒体形式 → 容器格式 → 编码格式** 分开：视频/音频；视频选容器后分别选视频编码与音频编码，音频只选音频编码。
媒体形式只区分结果是视频还是音频；转封装是视频编码中的“复制原始编码”，不是单独一种容器或媒体形式。
视频容器支持 MP4、MKV、MOV、WebM；视频编码支持 H.264、H.265、AV1、VP9，各容器只展示兼容组合。
音频输出支持 M4A、MP3、FLAC、WAV、OGG、Opus、AAC/ADTS；编码包括 AAC、MP3、Opus、Vorbis、FLAC、ALAC、PCM。PCM 的 16/24-bit 位深在高级参数中单独选择，基础编码列表统一显示为 PCM。
切换容器保留兼容编码，只归一化不兼容字段，并在界面说明这一规则；不清空无关的质量、裁剪与路径设置。
混合媒体/容器选择显示多种值，统一父级后再编辑子级；完整矩阵及验证见 [格式扩展记录](evidence/OUTPUT-FORMATS.md)。
其他基本设置保留预设、质量（仅视频）、分辨率（仅视频）、保存位置。
保存位置固定在设置面板底部，其余选项在中间滚动，避免格式选项增加后隐藏输出位置。
格式和用途不形成两套互相覆盖的控制。预设是一次填入参数，手动修改后按参数匹配显示“自定义”。

高级参数使用可展开的 Expander 分组显示：视频编码（CRF/码率/帧率/速度/硬件）、音频（音轨/码率/采样率/声道/PCM 位深）、裁剪与输出（起止秒数/元数据/文件名）、预设。
转封装隐藏画质、音频重编码和裁剪字段。音轨选择只在单项且已读取媒体信息时显示；字幕的保留能力遵循媒体管线的实际支持范围。
硬件默认自动；目前只有 H.264 提供已接入的硬件后端，H.265/AV1/VP9 明示为 CPU 编码，不能假装已支持相应 GPU 路径。
无可靠大小预测时不显示估算数字，实际体积在完成后展示。
自建预设保存编码、尺寸与硬件后端参数，不保存路径、输出名称、裁剪和源轨道编号。

## 检查和错误

读取后立即做兼容性检查；参数变化时重新计算。阻断原因就地显示，开始按钮只统计可开始项。
字幕丢失等非阻断风险在开始前显示。裁剪范围不完整、倒置或超出时长必须阻断，不能退化成全片转换。
错误正文使用可执行中文建议；错误码、日志和计划信息放“技术详情”。
输出文件始终不覆盖源文件；重名保留两个文件。转封装也必须遵守清除元数据的选择。

## 生命周期操作矩阵

| 状态 | 显示 | 可执行操作 |
|---|---|---|
| 读取中 | 文件占位、读取状态 | 选择、移除（取消对应读取） |
| 待开始 | 源摘要、目标摘要、兼容性提示 | 编辑、开始、移除 |
| 等待中/等待继续 | 不可变执行参数 | 移出队列并编辑、取消、复制 |
| 转换中/准备中/检查输出 | 阶段、百分比、速度、剩余时间 | 取消、复制为新任务、技术详情 |
| 正在保存 | 提交状态 | 等待完成、查看详情；拒绝取消 |
| 正在取消 | 保持卡片直至进程停止 | 等待确认，不立刻移除 |
| 已完成 | 源/输出大小、耗时、输出路径 | 打开文件、打开文件夹、再次转换、移除 |
| 失败/已中断/已取消 | 原因与下一步建议 | 重试、修改后转换、详情、移除 |
| 需处理 | 保存或恢复异常 | 查看详情、人工核对输出，禁止直接重复执行 |

移除仅改变工作台可见项目，不删除源/输出文件，不终止正在运行的任务。最近一批移除可撤销。
取消停止后台任务并清理临时输出；成功提交边界后不能取消。
重试保留当前卡片身份，关联一个新的执行 JobId；再次转换创建新卡片，保留原结果与参数。

## 队列、关闭和恢复

- 按钮明确写“暂停后续任务”；当前任务继续，不暗示能暂停 FFmpeg 进程。
- 重启先恢复工作台卡片和任务输出，调度器保持暂停，用户“继续队列”后才启动等待项。
- 已开始但未提交的任务在恢复后标为已中断。已持久化输出的提交任务恢复为成功，避免重复转换。
- 运行中关闭窗口，提供“继续转换”和“取消任务并退出”；退出等待取消/提交完成，再保存工作台。
- 等待任务和未开始文件正常保存；下次打开重读媒体信息，不无声开始转换。
- 历史是结果检索入口，不承担当前队列管理。历史清空仅删除记录，保留实际媒体文件。

## 设置生效范围

诊断中的“视频 / 音频 / 字幕”编解码器分组使用三列等宽 Grid 横向并排，默认折叠，独立控制展开。列表使用有界 ScrollViewer（320 DIP）和 LazyVStack，避免数百项同时展开拉长设置页；长名称和能力标记换行。其他类型有数据时另起一行。目录是核心支持清单，不等于工作台已经开放所有编码，也不将仅编译存在的硬件编码器标为本机可用。

并发调整作用于后续调度，降低并发不会取消已经执行的任务；回退与验证策略由任务开始时捕获。
默认输出和元数据选项用于新增文件，不覆写已有卡片。保存失败必须留在设置窗口并显示原因。

## 无障碍与验收

文件按钮、选择复选框、输出字段、执行按钮均有可读名称。Ctrl+O 添加文件、Ctrl+Shift+O 添加文件夹。
Tab 可达关键动作，Enter 不作为全局开始转换快捷键。对话框用系统焦点与 Esc 规则。
默认窗口、最小窗口、浅/深色、多选混合值、取消、失败、恢复与结果入口都应实测。
实际已验证范围及未验证项见 [UX 重构证据](evidence/UX-workbench-redesign.md)，不得把设计目标当作完成证明。
