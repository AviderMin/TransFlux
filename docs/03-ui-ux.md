# 03 · UI / UX 设计规范

> 修订 2026-11-01：转换工作台改为“格式工厂（Format Factory）”式布局；设置/诊断/关于移入顶栏右侧；
> 预设并入“目标格式参数”窗口；新增批处理设置窗口。以下为当前有效规范。

## 设计语言

采用 Windows Fluent 习惯：系统标题栏（自定义标题栏扩展）、原生文件选择器、InfoBar、ContentDialog、
TeachingTip 按需使用。Reactor 负责声明组件，控件实际为 WinUI 原生控件。首发不自绘滚动条、不用网页替代主界面。

视觉关键词：安静、清楚、可信。使用系统正文与强调文本资源；中文跟随系统字体。主操作每个区域一个；
进度采用细线和数值，错误同时含文字与图标。

## 信息架构

- **顶部标题栏（自定义，ExtendsContentIntoTitleBar）**：左侧应用图标 + “TransFlux”；
  右侧为图标操作区：**设置（含诊断）**、**关于**。设置与关于以 ContentDialog 覆盖层呈现。
- **主体：转换工作台**（无左侧导航栏，无独立“任务/预设/设置”页面）
  - **左侧：目标格式目录**，按 **视频 / 音频 / 图片** 分类：
    - 视频：MP4（H.264/AAC）、MKV（H.264/AAC）、MKV·转封装（流复制）
    - 音频：M4A（AAC）、FLAC、WAV
    - 图片：PNG / JPEG（首发禁用，悬浮说明“图片转换将在后续版本开放”）
    - 选中某格式即成为“当前目标格式”，新加入的文件按该目标建立任务；此处含 添加文件/添加文件夹。
  - **右侧：任务与进度列表**：工具栏（添加文件、添加文件夹、开始、暂停、删除、批处理设置）+ 任务行。
    每行：文件名、目标格式摘要、单项状态/进度、速度/ETA、齿轮（打开该项目的参数窗口）、移除。
    输出完成的行可打开所在文件夹或结果。

## 尺寸与资源

默认窗口 1280×820 DIP，最小 920×640 DIP；所有尺寸按 DIP。左目录固定 220–260 DIP，右侧任务区自适应。
间距采用 4/8/12/16/24/32；普通操作目标至少 32 DIP 高，主要按钮 40 DIP。圆角/颜色优先取主题资源。
动效 120–200ms，遵循系统减少动画设置。组件覆盖 default/hover/pressed/focused/disabled/loading/error/高对比。

## 页面与组件契约

| 组件 | 内容 | 关键交互与状态 |
|---|---|---|
| AppTitleBar | 图标+应用名（左）；设置、关于图标按钮（右） | 图标按钮 AutomationName+Tooltip 且非拖拽区；点击打开对应 ContentDialog |
| FormatCatalog（左） | 分类：视频/音频/图片；格式项；添加文件/文件夹 | 选中高亮；图片项禁用并解释；拖放由任务区承接 |
| TaskToolbar | 添加文件、添加文件夹、开始、暂停、删除、批处理设置 | 开始=入队全部就绪项并恢复队列；暂停=暂停队列（当前任务继续）；批处理仅在多选时可用 |
| TaskRow | 文件名、目标格式摘要、状态/进度、速度/ETA、齿轮、移除 | 单击选中（不打开）；双击/齿轮打开参数窗口；稳定 key=MediaId |
| ParameterDialog（目标格式参数） | 见下节，分组详尽 | ContentDialog 覆盖层，仅打开时挂载；改动即时回写该项 ConversionOptions |
| BatchDialog（批处理） | 与 ParameterDialog 相同的分组表单 | 标题“批处理设置（N 项）”；应用到全部选中项 |
| SettingsDialog（顶栏设置） | 外观/语言/输出/并发/自动降级/验证/日志清理 + 诊断分区 | 诊断：核心版本、编码器、适配器、已验证候选；保存后说明生效时机 |
| AboutDialog（顶栏关于） | 图标、名称、版本、MIT/FFmpeg(GPL) 说明 | 单一关闭 |

### ParameterDialog 分组（预设优先，允许具体数值）

1. **预设**：按当前模式/容器过滤的内置与自建预设；应用即填充下方参数；“保存为预设”用当前参数新建
   （内置预设不可覆盖，只能另存为）。
2. **视频**（仅视频目标）：质量挡位（较小体积/均衡/更高画质）+ **具体 CRF** 数值；**目标码率(kbps)** 数值；
   分辨率（保持原始 / 1080p 上限 / 自定义 宽×高 数值）；帧率数值；速度挡位（更快/均衡/更慢）。
3. **音频**：编码；码率(kbps) 数值；采样率(Hz) 数值；声道数 数值。
4. **裁剪**：开始/结束 时间码 `hh:mm:ss.mmm`（转封装禁用）。
5. **元数据**：清除个人信息 / 保留标题与章节。
6. **硬件**：自动 / CPU / NVIDIA NVENC / Intel QSV / AMD AMF（说明“不保证更小或更快”）。
7. **输出**：目录选择 + 文件名（默认源旁 `TransFlux Output`）。

数值留空表示“按挡位/源推导”；填写则精确覆盖（编码器实际参数见计划摘要只读详情）。
预设不再有独立页面，全部在此窗口内管理。

## 主流程细节

1. 左侧选中目标格式 → 添加文件/文件夹（或拖放）→ 立即出现“正在读取”占位行，探测完成逐项更新。
2. 双击某任务行或齿轮 → 打开该目标格式的参数窗口；保存后仅更新该项目（多选时用批处理设置统一）。
3. 点击“开始”把全部就绪项按各自参数入队并恢复队列；阻断项就地提示，绝不静默跳过。
4. “暂停”只停止启动后续任务，当前任务继续；删除仅移除未启动项（可撤销）。
5. 进度百分比最高 99%，验证/写入阶段单独文本，提交成功后 100%。
6. 设置/关于从顶栏打开为模态窗口；运行期间修改设置只影响新任务；并发下调在已有任务后生效。
7. 顶栏始终可见；键盘 Tab 顺序：顶栏 → 左目录 → 工具栏 → 任务列表；Esc 仅关闭当前弹窗。

## 键盘与无障碍

Ctrl+O 添加文件，Ctrl+Shift+O 添加文件夹，Delete 移除未启动选择项，Alt+Enter 打开选中项参数，
Ctrl+B 打开批处理设置。不要将全局 Enter 绑定为直接开始转换。所有图标按钮提供 AutomationName 与 Tooltip；
进度条提供范围或不确定状态；状态变化以文字补充颜色。屏幕阅读器对阶段变化播报，不逐帧播报百分比。
200% 文本缩放不截断关键动作。弹窗关闭后恢复原焦点。

## 用户文案

| 场景 | 建议文案 |
|---|---|
| 自动硬件选择 | “使用 NVIDIA 显卡编码 · 当前设置已通过测试” |
| 仅软件解码 | “CPU 解码 → 显卡编码”，不能写“全程 GPU” |
| 软件回退 | “显卡编码未能启动，已改用 CPU 从头转换。” |
| 磁盘不足 | “输出磁盘空间不足。请选择其他文件夹或释放空间后重试。” |
| HDR 阻断 | “此文件包含 HDR 信息。当前版本支持兼容的转封装，HDR 转码暂未开放。” |
| 图片分类 | “图片转换将在后续版本开放。” |
| 质量说明 | “均衡：兼顾画质与体积。实际大小取决于画面内容。” |
| 预设说明 | “内置预设不可覆盖，可另存为自建预设。” |

错误正文描述用户可执行动作；展开详情才展示错误码与 FFmpeg stderr。设置页解释“硬件加速不保证更小或更快”，
只放在相关选项附近。

## UI 完成定义

提交主工作台在空态/导入中/运行中/失败/批处理/参数窗口/设置/关于的浅色与深色截图，附键盘路径与 Narrator 检查。
主流程必须在真实 Reactor 原生窗口运行；HTML 原型与静态图片不能替代实现验收。

## P0 实施补充（2026-11-01）

- 右侧任务区为**表格**：列 `文件 / 目标格式 / 状态·进度 / 速度 / 输出 / 操作`；顶部筛选
  `全部 / 进行中 / 已完成 / 失败`，并提供 `清除已完成`。行内齿轮打开参数窗口，已完成行可直接打开/定位输出。
- 工具栏分层：主操作 `添加文件(主) / 添加文件夹`；选择级 `全选 / 删除 / 批量设置(N)`；
  队列级 `开始全部 / 暂停队列`（提示“仅暂停启动新任务，当前任务继续”）。
- 左栏“输出设置”：格式列表内部滚动；**质量快捷挡**（较小体积/均衡/更高画质，一键应用到已选项）；
  **输出位置固定可见**（更改/打开），主界面底部同时显示当前输出目录。
- 参数窗口分 **基本 / 高级** 两个页签：基本=预设/质量/分辨率/输出；高级=CRF、目标码率、帧率、
  音频采样率/声道、裁剪、元数据、硬件。数值带范围校验（CRF 0–51、码率、宽高 2–16384、帧率 1–240 等），
  并提供“清除具体数值（回到挡位推导）”与“同时应用到所有相同目标格式的任务”。
