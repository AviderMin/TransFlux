# 03 · UI / UX 设计规范

## 设计语言

采用 Windows Fluent 习惯：NavigationView 导航、系统标题栏、系统主题资源、原生文件选择器、InfoBar、ContentDialog、TeachingTip 按需使用。Reactor 负责声明组件，控件实际为 WinUI 原生控件。首发不自绘滚动条、不模拟 macOS 窗口按钮、不用网页替代主界面。

视觉关键词：安静、清楚、可信。使用系统正文与强调文本资源；中文跟随系统字体，不强制英文字体。主操作每个区域一个；卡片不铺满高饱和渐变；处理进度采用细线和数值，错误同时含文字与图标。

## 信息架构

一级导航：**转换、任务、预设、设置**。历史位于“任务”的“历史”页签；硬件能力与诊断位于设置，可从任务卡的设备标签跳转。不将 CPU/GPU 图表占据首页中心。

## 尺寸与资源

默认窗口 1280×820 DIP，最小 920×640 DIP；所有尺寸按 DIP，不能用物理像素硬编码。宽度 ≥1200 时导航展开，文件区自适应，设置面板 340–380 DIP；920–1199 时导航折叠，设置通过侧面板或页内切换显示，主操作始终可达。低有效分辨率由可滚动容器保证可达性，不强制窗口超出工作区。

间距采用 4/8/12/16/24/32；页面内边距 24，紧凑模式 16；普通操作目标至少 32 DIP 高，主要按钮 40 DIP。圆角与颜色优先取主题资源；分割线轻于正文；次要信息不能依赖低对比灰色传达关键内容。动效控制在 120–200ms，遵循系统减少动画设置。

组件必须覆盖 default / hover / pressed / focused / disabled / loading / error / high contrast，不仅提供浅色静态效果图。颜色通过资源集中定义，不散落十六进制字面量。

## 页面与组件契约

| 页面/组件 | 内容 | 关键交互与状态 |
|---|---|---|
| EmptyImport | 拖放区域、添加文件、支持说明 | 文件拖入高亮；目录拖入明确扫描方式 |
| MediaListRow | 文件名、缩略图、时长、视频/音频摘要、状态 | 行选中不等于打开；双击进入详情；菜单移除/定位 |
| OutputSettings | 用途、容器、质量、硬件、位置 | 多选显示混合值；预设变更显示将影响哪些选项 |
| AdvancedPanel | 流选择、缩放、裁剪、音频、元数据 | 按需展开，非法组合就地显示解释 |
| PlanSummary | 编码器、设备、预计体积范围、轨道舍弃提示 | 未知估计写“无法估计”；只读技术详情可复制 |
| QueueTaskCard | 状态、当前阶段、进度、速度、ETA、路径 | 排队可排序；运行可取消；失败可重试 |
| PresetEditor | 内置/自建预设、变更摘要 | 内置不可直接覆盖，可另存为；导入 JSON 需校验 |
| Settings | 外观、语言、输出、硬件、资源、核心、隐私 | 危险/耗资源选择有解释，保存后明确生效时机 |
| Diagnostics | 核心版本、设备能力、错误码、任务日志 | 报告脱敏预览后导出，无自动上传 |

默认预览为缩略图加媒体信息，不把内嵌视频播放器作为转换前置条件。首发用系统默认程序打开已验证输出；不自动播放。

## 主流程细节

1. 导入即时出现“正在读取”占位行，探测结束逐项更新；不用模态 loading 阻塞整个窗口。
2. 同一工作台可保持草稿；切换导航不会丢选择。尚未保存的自建预设离开时提示，普通用途调整不反复弹确认。
3. 开始前就地列出阻断项和警告；按钮为“开始 8 项”，存在 2 项阻断时可用“开始 6 项”，旁边明确“2 项需处理”，绝不静默消失。
4. 启动后进入任务页，焦点移至队列标题；转码卡上的百分比最高显示 99%，验证与写入阶段有单独文本，提交成功后才为 100%。
5. “暂停队列”旁说明“当前任务继续”；取消运行任务需一次确认，多选取消汇总确认。删除未启动项可短暂撤销。
6. 重试创建新 attempt，旧错误与路径保留。运行期间修改设置只影响新任务；并发限制下调待已有任务结束后生效。

## 键盘与无障碍

Ctrl+O 添加文件，Ctrl+Shift+O 添加文件夹，Ctrl+A 仅在文件列表焦点内全选；Delete 移除未启动选择项；Alt+Enter 打开详情。不要将全局 Enter 绑定为直接启动转换。Tab 顺序为导航 → 文件区 → 设置区 → 主操作，弹窗关闭后恢复原焦点；Esc 仅关闭当前面板/弹窗，不取消运行任务。

所有图标按钮提供 AutomationName 和 Tooltip；进度条提供范围或不确定状态；以状态文本补充颜色。屏幕阅读器对阶段变化播报，不每 250ms 播报百分比。键盘聚焦文件列表时不能因后台进度更新丢失选中项；200% 文本缩放时不截断关键动作。

## 用户文案

| 场景 | 建议文案 |
|---|---|
| 自动硬件选择 | “使用 NVIDIA 显卡编码 · 当前设置已通过测试” |
| 仅软件解码 | “CPU 解码 → 显卡编码”，不能写“全程 GPU” |
| 软件回退 | “显卡编码未能启动，已改用 CPU 从头转换。” |
| 磁盘不足 | “输出磁盘空间不足。请选择其他文件夹或释放空间后重试。” |
| HDR 阻断 | “此文件包含 HDR 信息。当前版本支持兼容的转封装，HDR 转码暂未开放。” |
| 已中断 | “上次转换未完成，可以从头重试。” |
| 质量说明 | “均衡：兼顾画质与体积。实际大小取决于画面内容。” |

错误正文描述用户可执行动作；展开详情才展示错误码、FFmpeg stderr 与技术计划。设置页解释“硬件加速不保证更小或更快”，只放在相关选项附近，不作为每次转换的警告弹窗。
